Coauthoring

GETPOST{{.CoauthoringPrefix}}/…

Socket.IO polling transport for document open, save, and license handshake.

  • GET …?transport=polling — session open / long-poll receive
  • POST …?transport=polling&sid=… — send auth, saveChanges, etc.

Save flow (single-user)

Client sends isSaveLock → saveChanges → server responds unSaveLock, then converts cache and POSTs to the integrator callbackUrl with status 2 or 6.
