go-office

Embedded Go document server compatible with ONLYOFFICE / Euro-Office browser clients.

Quick links

  • Document demo — open sample files in the editor
  • Health check — {{.HealthURL}}

What to do next

  • Fetch Euro-Office assets if you have not already: go run ./cmd/fetch-assets
  • Add documents under {{.SamplesDir}} — they appear on the demo landing page
  • Open the demo and pick a file to edit
  • Debug logging is enabled automatically in demo mode (-debug or GO_OFFICE_DEBUG=1 otherwise)

Routes

  • / — this page
  • {{.OfficeBase}}/ — editor assets and coauthoring
  • {{.APIBase}}/demo/config — editor init JSON (API)
  • {{.APIBase}}/demo/callback — save callback stub (API)
